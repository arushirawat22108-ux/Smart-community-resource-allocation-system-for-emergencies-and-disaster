CRAS AI Prediction Module

Objective

Develop a module that estimates the risk of resource shortages during emergencies.

Planned Inputs

* Resource type
* Current available quantity
* Incoming resource requests
* Recent resource consumption
* Waiting requests and affected population

Planned Outputs

* Predicted shortage risk
* Confidence score, if supported by the selected prediction method
* Information for the scheduling module to use when prioritising requests

Development Plan

1. Define the input data format.
2. Establish a baseline shortage-risk calculation.
3. Evaluate whether historical data is sufficient for machine-learning prediction.
4. Test predictions against sample scenarios.
5. Document results and integrate the module with the backend.

Status

Planning and independent development in progress.
