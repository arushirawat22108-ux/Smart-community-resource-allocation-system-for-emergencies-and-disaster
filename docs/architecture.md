Community Resource Allocation System (CRAS)

Project Overview

CRAS is designed to allocate limited community resources during emergencies using database management,
operating-system scheduling concepts, AI-based prediction, and a web-based interface.

Independent Development Modules

1. Arushi — Team Leader, AI and System Integration

* Overall project planning and coordination
* System architecture and module integration
* AI-based resource shortage prediction and confidence score
* Integration of database, scheduling, and frontend modules
* System-wide testing, evaluation, and final presentation

2. Vinayak — Database and Backend

* Database schema and resource inventory
* Resource request and allocation APIs
* Data validation and transaction handling
* Backend development and database integration

3. Aaman — OS Scheduling and Resource Allocation

* Dynamic priority calculation
* Priority scheduling and priority aging
* Resource allocation under limited availability
* Scheduling queues and allocation logic

4. Tulsi — Frontend and Testing

* User dashboard and request forms
* Resource manager interface
* GIS display and map integration
* Functional testing and interface validation

Development Process

Each member independently develops and tests their assigned module. 
The modules are integrated into the main branch after review and successful testing.

Expected Outcome

A working CRAS application that manages emergency resource requests, prioritizes urgent needs, 
allocates available resources, and presents resource information through a user-friendly interface.
